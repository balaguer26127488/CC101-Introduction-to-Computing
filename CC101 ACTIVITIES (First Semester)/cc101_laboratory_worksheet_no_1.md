## III. Background
Every computer, whether a desktop tower or a laptop, is built from hardware components that fall into four general categories: input devices (send data into the computer, e.g., keyboard, mouse), output devices (present processed data to the user, e.g., monitor, speakers), the processing/storage unit (CPU, RAM, and drives that compute and hold data), and ports/peripherals (connectors that link external devices to the system unit). Windows 11 also provides several built-in tools — Settings, System Information, Device Manager, and Task Manager — that let you inspect these components without opening the case. This activity uses both direct observation and these software tools.

## IV. Procedure

### Part A - Physical Inspection (5-10 minutes)
1. Examine the computer unit in front of you. If it is a desktop, look at the system unit (tower/case); if it is a laptop, examine the whole chassis.
2. List all the input devices you can see or that are built in (e.g., keyboard, mouse, touchpad, webcam, microphone).
3. List all the output devices you can see or that are built in (e.g., monitor/screen, speakers, headphone jack).
4. Locate the available ports on the unit (USB-A, USB-C, HDMI, audio jack, Ethernet/LAN, power, etc.) and note what each one is typically used to connect.

### Part B - System Identification (Settings)
5. Click **Start** $\rightarrow$ **Settings** $\rightarrow$ **System** $\rightarrow$ **About**.
6. Record the Device name, Processor, Installed RAM, Device ID, and System type shown under Device specifications.
7. Scroll down to Windows specifications and record the Edition, Version, and OS build.

### Part C - Detailed Hardware Check (System Information)
8. Press the Windows key, type **System Information**, and open it (this runs the `msinfo32` tool).
9. On the System Summary page, record the System Manufacturer, System Model, BIOS Version/Date, and Total Physical Memory.

### Part D - Device Manager Exploration
10. Right-click the Start button and choose **Device Manager**.
11. Expand at least six (6) categories for example: Display adapters, Network adapters, Sound/video/game controllers, Disk drives, Keyboards, Mice and other pointing devices, and Universal Serial Bus controllers.
12. For each category you expand, write down the specific device name Windows lists (this is the exact model of that component in your unit).

### Part E - Performance and Storage Check (Task Manager)
13. Open **Task Manager** (`Ctrl+Shift+Esc`) and click the **Performance** tab.
14. Record the CPU name, base speed, and number of cores; the total Memory (RAM) and its speed; and the Disk type (HDD or SSD) and capacity.

### Part F - Software Snapshot (Optional / Bonus)
15. Go to **Settings** $\rightarrow$ **Apps** $\rightarrow$ **Installed apps**. List five (5) installed applications and classify each as System Software or Application Software.
